PHASE 2 TRAINING PWA

FREE HOSTING
Recommended: GitHub Pages, Cloudflare Pages, or Netlify free static hosting.
No backend, database, login, analytics, or subscription is required.

IPHONE INSTALL
1. Publish this folder to an HTTPS static host.
2. Open the live URL in Safari on iPhone.
3. Tap Share > Add to Home Screen.
4. Open Phase 2 from the Home Screen once online so assets are cached.
5. Test in Airplane Mode.

DATA
Workout data stays in localStorage on that browser/site origin. Use MORE > Export backup regularly.
If you change the site domain/host, import your backup into the new copy.

8-WEEK REFRESH
The site flags the end of the 8-week phase. A ChatGPT automation has separately been scheduled every 8 weeks to generate the next coaching phase from available progression context. Because a static site cannot securely receive ChatGPT-generated program changes by itself without a backend/API, updating the hosted program file remains a deployment step. This avoids paid infrastructure and protects the zero-cost architecture.
